# João Vitor Leonardi

**Analista de Negócios Júnior | Transformação Digital | Engenharia de Requisitos**

Brasília, DF · Graduando em Ciência da Computação (UniCEUB)

Transformo necessidades de negócio em requisitos claros e protótipos navegáveis que o time de desenvolvimento consegue construir e validar.

## O que eu faço

- **Requisitos:** levantamento de necessidades, regras de negócio, histórias de usuário e critérios de aceitação.
- **Processos:** análise e melhoria de processos, com Scrum, ITIL e modelagem.
- **Protótipos:** fluxos navegáveis em HTML, CSS e JavaScript para validar o desenho antes do desenvolvimento.
- **Validação:** conferência das entregas contra os requisitos, com evidências e acompanhamento das correções.
